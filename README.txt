SAM IRRIGATION — INTERFACE GITHUB PAGES
======================================

Fichiers :
- index.html
- style.css
- app.js

Mise en ligne :
1. Créer un dépôt GitHub.
2. Placer les trois fichiers à la racine.
3. Settings > Pages.
4. Source : Deploy from a branch.
5. Branch : main, dossier /(root).

L’interface utilise Chart.js depuis un CDN et les prévisions Open-Meteo.
Une connexion internet est nécessaire.

La localisation par défaut correspond à une position proche de Quissac.
Cliquer sur le bloc LOCALISATION pour utiliser la géolocalisation ou afficher
la saisie manuelle des coordonnées.
