FICHIERS À REMPLACER POUR LE NOUVEAU LOGO
=======================================

Remplace dans ton dépôt GitHub les fichiers suivants :
- index.html
- service-worker.js
- app-icon.png
- icon-512.png
- icon-192.png
- apple-touch-icon.png
- favicon-32.png
- favicon-16.png
- favicon.ico

Ensuite :
1. attends le redéploiement GitHub Pages ;
2. recharge le site sur ordinateur avec Ctrl + F5 ;
3. sur téléphone, ferme puis rouvre l'application ;
4. si l'ancienne icône reste affichée, supprime l'application de l'écran d'accueil puis réinstalle-la.
